# Reflection: Cloud Computing and Version Control

Cloud computing is now part of my everyday life because many applications and services I use depend on the internet. It helps people store files, communicate, study, and use different applications without needing to install or manage large systems on their own computers.

One cloud service that I use regularly is Google Drive. It is an example of Software as a Service (SaaS) because it provides online storage and tools that users can access through the internet. It uses a Public Cloud deployment model because many people can use the service with their own accounts.

Another cloud service I use is Canva. Canva is also a SaaS because it provides online tools for creating designs, presentations, and other digital content. It uses a Public Cloud deployment model because the service is available to different users anywhere with an internet connection.

The third cloud service I use is Messenger. It is considered SaaS because it provides an online communication platform where users can send messages and share files. It also uses a Public Cloud deployment model because it is available to many users around the world.

Git and GitHub are important when working with cloud projects because they help developers organize and manage their work. Version control allows users to track changes, save previous versions, and fix mistakes easily. GitHub also helps teams work together because members can share files, review updates, and avoid problems when changing project files.

In cloud infrastructure, version control is useful because it keeps important files such as codes, settings, and documents organized. It helps make projects safer and easier to manage.

Overall, learning cloud computing and version control gives me important knowledge about how modern applications work. These skills can help me create and manage better technology projects in the future.
